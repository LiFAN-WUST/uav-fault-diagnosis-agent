# Security

This repository is a public research showcase and intentionally does not
contain the production backend, graph data, deployment credentials, user
uploads, or raw agent traces.

Please do not report suspected credentials or private data in a public issue.
Contact the maintainer through a private channel instead.

Never commit API keys, tokens, cookies, SSH keys, passwords, `.env` files,
production databases, host-specific paths, user-submitted evidence, or
unpublished research material. Before every release, run the repository audit
and review the complete Git history and all branches/tags.
