# Contributing

This is a curated research showcase rather than the complete implementation
repository. Contributions should preserve the public/private boundary and
must not add production data, credentials, raw traces, or unpublished method
details.

Before opening a change:

1. run `pwsh -File scripts/check_repo.ps1`;
2. run `npm ci && npm run build` in `frontend/`;
3. document the provenance and license of any new asset;
4. describe limitations without presenting a placeholder as a scientific
   result.
