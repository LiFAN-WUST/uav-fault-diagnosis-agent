# Demonstration guidance

The demonstration should show the deployed interface, not source code or
credentials. A suitable scenario is a four-rotor UAV that develops reduced
thrust, rising motor temperature, and RPM fluctuation during a fixed-thrust
task. Show the evidence intake, bounded analysis progress, structured report,
inspection order, and operating boundary.

Do not publish the production URL, reviewer account, API key, private IP,
flight log, or user-uploaded image. A screenshot or redacted recording is
enough for this public showcase.
