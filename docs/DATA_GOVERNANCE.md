# Data governance

This public showcase contains no production database, user-submitted text,
images, flight logs, access logs, cookies, credentials, or raw agent traces.

Any future sample must document its source, license or permission, aircraft or
simulator context, schema and units, split and seed, de-identification, and
known limitations. If redistribution rights are unclear, publish metadata and
not the data.

User evidence is operational material, not training data by default. It must
not be reused for training, benchmarking, or public examples without explicit
authorization and de-identification.
