# Reproducibility

This repository is reproducible as a public interface and UI build, not as the
complete private diagnosis engine. The private archive records the full
production source, deployment templates, environment requirements, and
logical Neo4j recovery procedure.

For any future scientific release, freeze the code commit, dataset manifest,
random seed, split definition, configuration, metric definitions, failure
cases, and provenance. Simulation-only results must not be generalized to
real-flight effectiveness without independent validation.

The public release deliberately withholds raw telemetry, private knowledge
graphs, complete prompts, model traces, and unpublished method details.
